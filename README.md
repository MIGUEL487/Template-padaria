# O Refúgio
Landing page de demonstração em português. Vite + React + TypeScript, GSAP e Motion.

```sh
npm ci --cache /tmp/refugio-npm
npm run build
npm run preview -- --port 4173
```

Use o checkout existente: `/workspace/Template-padaria`. Não é necessário criar worktrees. Nenhum segredo ou backend é necessário. Os materiais originais foram preservados.

O anexo foi usado como direção criativa. Esta implementação prioriza o site funcional: não corresponde integralmente a todos os itens do documento. Veja `docs/CHECKLIST.md` para diferenças e validações pendentes.

Fontes: os arquivos Bringbold Nineties, Kangmas e Balney não foram fornecidos. A interface usa Georgia e Arial/sans-serif locais, sem afirmar que as fontes de marca foram carregadas. Se utilizar fontes Zarmatype, confirme a licença comercial antes de vender o template.

Pedidos são demonstração até configurar um número real; endereço, horários, avaliações, preços e história não representam uma empresa real.
